## 🧠 What is a 4:1 Multiplexer?

A **4:1 Multiplexer** is a combinational circuit that selects **one of four input signals** and forwards the selected input to a single output.

It uses **two select lines** to determine which input is connected to the output.

```text
                 ┌───────────────┐
      I0 ───────►│               │
      I1 ───────►│               │
      I2 ───────►│    4:1 MUX    ├──────► Y
      I3 ───────►│               │
                 │               │
      S1 ───────►│ Select        │
      S0 ───────►│ Lines         │
                 └───────────────┘
```

---

## 📊 Truth Table

|  S1 |  S0 | Selected Input | Output Y |
| :-: | :-: | :------------: | :------: |
|  0  |  0  |       I0       |    I0    |
|  0  |  1  |       I1       |    I1    |
|  1  |  0  |       I2       |    I2    |
|  1  |  1  |       I3       |    I3    |

Therefore:

```text
S1 S0 = 00 → Y = I0
S1 S0 = 01 → Y = I1
S1 S0 = 10 → Y = I2
S1 S0 = 11 → Y = I3
```

---

## 🔢 Boolean Expression

The 4:1 multiplexer can also be represented using the Boolean expression:

```text
Y = (~S1 & ~S0 & I0)
  | (~S1 &  S0 & I1)
  | ( S1 & ~S0 & I2)
  | ( S1 &  S0 & I3)
```

This demonstrates how a multiplexer can be constructed using fundamental logic operations.

## 🧪 Functional Verification

A Verilog testbench was developed to verify the functionality of the design.

The simulation tested all four possible select-line combinations:

```text
00 → I0
01 → I1
10 → I2
11 → I3
```

The simulated output was compared with the expected truth table to confirm correct operation.

### Simulation Result

The waveform confirmed that the output follows the selected input according to the values of `S1` and `S0`.

## 🔍 RTL Schematic

The RTL schematic generated by Vivado was inspected to understand how the high-level Verilog description was interpreted as digital hardware.

The schematic provides a visual representation of the multiplexer logic before synthesis.

---

## ⚙️ Synthesis

The design was synthesized using **AMD Vivado 2026.1**.

Synthesis converts the RTL description into a hardware-oriented netlist suitable for implementation on the target FPGA.

The synthesized design was inspected to understand how the multiplexer logic is mapped onto FPGA resources.

---

## 🧩 FPGA Implementation

After successful synthesis and implementation:

```text
RTL Design
     ↓
Simulation
     ↓
Synthesis
     ↓
Implementation
     ↓
Bitstream Generation
     ↓
PYNQ-Z2
```

The generated bitstream was programmed onto the **PYNQ-Z2 FPGA development board**.

The design was then verified using physical inputs and LED output.

The overall Vivado flow of simulation, synthesis, implementation and bitstream generation is also the standard workflow used in FPGA development.

---

## 🔌 Hardware Testing

The 4:1 MUX was tested on the **PYNQ-Z2** using the available board inputs and LEDs.

The select lines were used to choose between the four input signals.

```text
Select = 00 → Input 0 selected
Select = 01 → Input 1 selected
Select = 10 → Input 2 selected
Select = 11 → Input 3 selected
```

The hardware output was verified against the expected simulation behavior.
